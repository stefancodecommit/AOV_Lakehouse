# Dashboard assets

Put the logo files here, named as in `config.yaml` (`dashboard.logo` and
`dashboard.logo_dark`, by default `eur_logo.svg` and `eur_logo_dark.svg`). The dashboard
shows the logo at the top of the sidebar when the file exists, the dark variant in dark
mode; without a logo file the sidebar shows the project note as text instead.

The Erasmus University Rotterdam logo used on the development machine was taken from the
official website (www.eur.nl): the `logo` symbol in its SVG sprite, coloured as the site
does (#002328 on light backgrounds, white on dark).

Files in this folder are not committed to git (see `.gitignore`), except this README.
A university logo is a registered trademark: check the brand guidelines (or ask your
teacher) before using it, and especially before publishing the repository.
